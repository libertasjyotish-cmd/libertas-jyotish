# 多言語ページの作り方

日本語ページ（`/ja/*`）を含むすべての言語ページは、`templates/` と `locales/` から生成する。
`ja/index.html` などの生成物は直接編集しない。編集しても次回の生成で上書きされる。

## 構成

| 場所 | 役割 |
| --- | --- |
| `templates/*.html` | 全言語共通の構造・CSS・スクリプト。文言は `{{t.キー}}` で参照する |
| `locales/<lang>.json` | 言語ごとの文言（`strings`）とメタ情報（`meta`） |
| `scripts/build-i18n.mjs` | 生成スクリプト |
| `<lang>/*.html` | 生成物（コミット対象。Vercelはこれをそのまま配信する） |

## 手順

```bash
# 生成（locales にある全言語）
npm run build:i18n

# 生成物が最新かどうかの検査（CIと同じ）
npm run check:i18n
```

レイアウトやスクリプトを直すときは `templates/` を、文言を直すときは `locales/<lang>.json` を編集し、
`npm run build:i18n` を実行して生成物ごとコミットする。

## テンプレートの記法

| 記法 | 用途 |
| --- | --- |
| `{{t.キー}}` | HTML本文に文言を埋め込む |
| `{{t.キー\|attr}}` | HTML属性値に埋め込む（`"` などを実体参照化する） |
| `{{t.キー\|js}}` | JavaScript の文字列リテラル内に埋め込む |
| `{{t.キー\|tpl}}` | テンプレートリテラル（バッククォート）内に埋め込む |
| `{{lang}}` | 言語コード。内部リンク（`/{{lang}}/mypage`）や API に渡す言語指定に使う |
| `{{htmlAttrs}}` | `<html>` の属性。アラビア語では `lang="ar" dir="rtl"` になる |
| `{{fontHref}}` `{{fontFamily}}` | 言語別のWebフォント |
| `{{langSwitcher}}` | フッターの言語切替。一覧は `scripts/build-i18n.mjs` の `LANG_SWITCH` で管理する |
| `{{>name}}` | `templates/partials/name.html` を展開する（全ページ共通の断片用） |

文言の中に `%LANG%` と書くと、生成時にその言語コードに置き換わる（文言内のリンク用）。

## 共通スクリプトへの文言の渡し方

`js/site-menu.js`（ヘッダー）と `js/checkout-links.js`（価格表示）は全言語で共有するため、
文言を直接持たず `templates/partials/i18n-globals.html` が埋め込む `window.LJ_I18N` から受け取る。
メニュー名や価格ラベルを変えるときも `locales/<lang>.json` を編集する。
価格は API（`/api/checkout-links`）が返す金額を、日本語以外では閲覧言語の書式に整形して表示する。

## 言語を追加するとき

1. `locales/ja.json` をコピーして `locales/<lang>.json` を作り、`meta` と `strings` を翻訳する。
   未翻訳のキーは日本語のまま生成され、ビルド時に件数が警告表示される。
2. `npm run build:i18n` を実行し、生成された `<lang>/*.html` をコミットする。
3. 言語非依存URL（`/success` など）からの転送先に含めるため、`js/lang-redirect.js` の
   `AVAILABLE_LANGS` にその言語を追加する。
4. `sw.js` の `CACHE_NAME` を更新して、古いキャッシュを破棄する。
5. メール認証の文面（`api/jyotish.js` の `AUTH_MAIL`）にその言語を追加する（未追加の言語は英語で送信される）。

なお、完全鑑定書（`api/_report.js`）はまだ日本語固定のため、日本語以外の公開（`AVAILABLE_LANGS` への追加）は
鑑定書の多言語化後に行う。
