# 鑑定書設計書: Karma & Dharma — The Calling of This Lifetime

日本語名: **カルマとダルマ ― 今世の天命**
商品キー（実装時）: `karma`
状態: 設計のみ（実装は 4 商品公開後）

---

## 1. 商品の目的と読者の問い

読者が抱えている問いに、出生図の根拠を示して答える鑑定書。

- 生まれ持ったカルマ・宿命・課題・試練は何か
- 私がこの世に生を受けた使命とは何か。今世で成すべきことは何か
- どんな役割を持って生まれてきたのか。自分にしかできないことは何か
- 私が「本当に生きている」と感じられることは何か

分量: 8 章＋付章、約 30 ページ（palm と同等）。

## 2. オカルト回避の原則（語調規則 = KARMA_VOICE）

「前世を当てる」書ではなく、「出生図から、生まれ持った設計と課題、力が最も発揮される方向を読み解く」自己理解の書として書く。

1. **根拠を必ず示す**: すべての主張に配置名（例: ケートゥ第4室、アートマカーラカ=金星 第9室）を添える。付章に根拠表を載せる。
2. **語の定義を固定する**
   - カルマ = 「生まれ持った設計と、繰り返しやすい癖・課題」（過去生の断定はしない）
   - ダルマ = 「その人の力が最も自然に発揮され、周囲に役立つ方向」
   - 天命／Calling = 「今生で引き受けるとよい役割」（義務・運命の強制ではない）
   - 試練 = 「鍛えられる領域と、その意味」（罰・報いという語は使わない）
3. **表現の型**: 「この配置は〜を示す」「〜と読む」「〜に寄る」。「あなたは前世で〜だった」「〜する運命だ」「〜しなければ不幸になる」は禁止。
4. **既存の安全規則を全適用**: 医療・法律・金銭・生死・災厄の断定なし、依存や恐怖を煽る表現なし（`_report.js` の `findViolations` を流用）。ケートゥ・第8室・第12室・土星は「手放し」「深化」「熟成」の語で扱い、「喪失」「不幸」「業が深い」等は使わない。
5. **決めつけない**: 職種名・具体の人物・出来事は断定せず、「性質」「方向」「場面」で書く（career と同じ規則）。
6. **必ず救いで閉じる**: 課題の章も「その課題を通じて手に入る力」で終える（daily の「この先に待っているもの」と同じ思想）。

## 5. 章構成（KARMA_CHAPTERS）

各章の `pick` は上表の要素から必要分のみ渡す。`schema` は既存商品と同じく JSON 指定、文字数は日本語基準（他言語は terms で置換）。

### summary — 魂の設計図（見取り図）
- pick: ラグナ、月、太陽、ナクシャトラ・神格、AK、AmK、ラーフ／ケートゥ軸、現在のダシャー
- schema:
  - `catchphrase`: この人の生まれ方を一文で（30字）
  - `essence`: ラグナ・AK・節点軸から読む「この生の設計」の全体像（300字）
  - `karmaTheme`: 生まれ持った課題を一言で（40字）
  - `dharmaTheme`: 力が発揮される方向を一言で（40字）
  - `gifts[3]`: 生まれ持った資質（各30字）

### ch1 — 第1章 何者として生まれたか（ラグナとアートマカーラカ）
- pick: ラグナ（サイン・支配星の位置）、AK（惑星・サイン・ハウス・品位・ナクシャトラ）、カラカムシャ
- schema: `intro`（AK の考え方 150字）、`text`（AK が示す魂の目的、カラカムシャの示す舞台 500字）、`coreDesire`（この生で満たしたい根源の欲求 200字）、`shadow`（AK の惑星が未熟なときに出る癖 150字）

### ch2 — 第2章 持って生まれたカルマ（ケートゥ）
- pick: ケートゥ（ハウス・サイン・ナクシャトラ・支配星・同座）、その支配星の位置、第12室
- schema: `intro`（ケートゥ＝「すでに身についているもの」の読み方 150字）、`mastered`（生まれつき得意で、意識せずできること 300字）、`pattern`（そこに戻りたがる癖・繰り返しやすい場面 300字）、`release`（手放すとよいこと 200字。「捨てる」ではなく「握らない」の語調）

### ch3 — 第3章 今生の課題と試練（ラーフと土星）
- pick: ラーフ（ハウス・サイン・ナクシャトラ・支配星・同座）、土星（ハウス・品位・アスペクト）、第6・8室
- schema: `intro`（ラーフ＝伸ばす方向、土星＝鍛える領域 150字）、`rahu`（未熟だが伸ばすべき領域と、飢えとして現れるもの 400字）、`saturn`（時間をかけて返す課題、遅れの意味 350字）、`trials[3]`（人生で繰り返しやすい試練の型 各40字）、`gift`（その試練を越えたときに手に入る力 200字）

### ch4 — 第4章 試練が来る時期と、その意味（サデサティとダシャー）
- pick: サデサティ（期間・フェーズ）、ダシャー現在・過去切替・今後、ラーフ／ケートゥ／土星のダシャー期
- schema: `intro`（時期を「何を学ぶ期間か」で読む考え方 200字）、`past`（過去の切替期に何が鍛えられたと読めるか 300字。年は確定データのみ）、`now`（現在のダシャーが課題とどう関わるか 350字）、`coming[]`（今後の期の `lord` と `text` 150字。数は確定データ分）、`meaning`（時期を恐れず使う姿勢 200字）

### ch5 — 第5章 使命の方向（ダルマとカルマの家）
- pick: 第9室・第10室（支配星・在住・品位）、AmK、木星、ヨーガ、アシュタカヴァルガ第9・10室
- schema: `intro`（第9室＝信念と導き、第10室＝世に返す行為 150字）、`ninth`（何を信じ、何を学び、何を伝える人か 350字）、`tenth`（世の中でどんな役割を担うと力が出るか 350字。職種名は書かない）、`amatya`（AmK＝使命を支える力 200字）、`roles[3]`（役割の性質 各40字。例: 人を結ぶ・型を整える・未知を開く）

### ch6 — 第6章 自分にしかできないこと（カラカムシャと三角座）
- pick: ダルマ・トリコーナ（1・5・9）の在住・支配星、カラカムシャとそこから見た第1・5・9・10、AK と AmK の関係（同座・アスペクト・ハウス関係）
- schema: `intro`（D9 で見る「魂の舞台」の考え方 150字）、`unique`（他の人には替えがたい、この人固有の組み合わせ 400字）、`combination`（AK と AmK の関係が示す「目的と手段」のかみ合い 250字）、`signs[3]`（自分の道に乗っているときのサイン 各40字）

### ch7 — 第7章 「生きている」と感じる瞬間（月・第5室・ナクシャトラ）
- pick: 月（サイン・ハウス・品位・ナクシャトラ・パダ・神格）、第5室、金星、第4室（心の休息）
- schema: `intro`（月＝魂が安らぎ喜ぶ場所 150字）、`joy`（生きていると感じる場面・行為・関係の性質 400字）、`deity`（ナクシャトラの神格の物語が示す「喜びの型」 250字）、`drain`（逆に生気を失いやすい条件 200字）、`practices[3]`（日々の中で喜びに戻る小さな行為 各40字）

### ch8 — 第8章 今世で成すべきこと（総括）
- pick: summary と同じ＋現在のダシャー＋第3章の trials
- schema: `calling`（この生の天命を、本書の根拠を束ねて一段落で 400字）、`avoid`（迷いやすい脇道 200字）、`firstStep`（今のダシャーで踏み出す最初の一歩 250字）、`message`（決めつけず、しかし背中を押す締めの言葉 200字）

### appendix — 付章 根拠表
- コードで生成（AI なし）: 使用した配置の一覧表（惑星／ハウス／サイン／ナクシャトラ／品位）、AK・AmK・カラカムシャ、ラーフ／ケートゥ軸、第9・10・12室の支配星、サデサティ期間、ダシャー年表、用語の定義（第2節の語の定義を掲載）。
